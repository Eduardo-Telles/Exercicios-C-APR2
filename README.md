## ▶️ Como compilar e executar

Você precisa de um compilador C, como o [GCC](https://gcc.gnu.org/). No Windows, uma opção é instalar o [MinGW](https://www.mingw-w64.org/) ou usar o WSL.

```bash
git clone https://github.com/Eduardo-Telles/NOME-DO-REPOSITORIO.git
cd NOME-DO-REPOSITORIO
gcc 01-basico/nome_do_arquivo.c -o programa
./programa
```

No Windows (PowerShell), o último comando é `.\programa.exe`.

Troque `01-basico/nome_do_arquivo.c` pelo caminho do exercício que quiser rodar. Para ver avisos úteis durante a compilação, use `gcc -Wall`.
